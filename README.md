# BI Gestão Sem Caos — site

Site de apresentação do BI Gestão Sem Caos (produto da Gestão Sem Caos, consultoria empresarial).
Todas as telas e números do site são fictícios, criados para demonstração.

- `index.html`: o site inteiro (um arquivo só).
- Publicação: GitHub Pages (ramo main, raiz) com o domínio `bi.gestaosemcaos.com.br` (arquivo CNAME). O `Dockerfile` (nginx) serve para publicar em outro servidor, se precisar.
